# kr2-corpus

史部文献プレーンテキスト・コーパス（正史・編年・紀事本末・別史・雜史・詔令奏議・傳記・史鈔・載記・時令・地理・職官・政書・目錄・史評、579件・約690MB）

## 概要

本リポジトリは、Kanseki Repository（漢籍リポジトリ、通称Kanripo）が公開する漢籍テキストデータのうち史部（KR2）から、機械可読なプレーンテキストを抽出・整形したコーパスである。KR-Catalog の史部目録に載る581件のうち、Kanripo側にリポジトリのある579件を収録する。残る2件はリポジトリが公開されておらず、収録できない（catalog.csv 参照）。

## 出典と作成方法

- 底本データ: Kanseki Repository（https://github.com/kanripo 、1文献1リポジトリ構成）
- 採用版本: 各リポジトリの master ブランチ（全件）。採用ブランチと取得時コミットSHAは catalog.csv の witness・commit 列に全件記録
- master の底本（各本文ファイルの BASEEDITION による実測）: WYG（四庫全書文淵閣本）530件、SBCK（四部叢刊）47件、tls 1件、MJSY 1件。文献ごとの値は catalog.csv の baseedition 列にある
- 分類・書誌典拠: kanripo/KR-Catalog の史部目録（KR/KR2a.txt〜KR2o.txt、コミット 781711923e2ce6f82f6dacfb8576cd80774b7ec0）
- 取得日: 2026-10-07

## フォルダ構成

類／文献の二層構造（例: `KR2a/KR2a0002.txt`）。1作品1ファイル（多巻本も分割せず1ファイルに収録）。分類・書誌などの意味情報はすべて catalog.csv に持たせる。

```
kr2-corpus/
├── KR2a/ 〜 KR2o/     各類（類／文献の二層）
├── catalog.csv         書誌・分類・取得情報
├── LICENSE             CC BY-SA 4.0 ライセンス全文
├── NOTICE_KANRIPO.md   底本の出典・ライセンス・加工内容の詳細
└── README.md           本ファイル
```

## テキスト整形方針

整形には corpus-search-toolkit の `scripts/kanripo_convert.py`（v1.3.0）を用いた。kr5-corpus・kr1-corpus と同じ規則である。

- 底本のmandoku形式（org-mode系）テキストから本文を抽出。**本文の文字そのものには改変を加えていない**（異体字の統一、Unicode正規化、外字参照の置換をしていない）
- 行頭が「#」の行は除去（冒頭のメタデータ行 #+TITLE 等のほか、本文の途中にある `# src:`・`# dating:`・`#+PROPERTY:` などの行を含む。書誌情報は catalog.csv へ）
- 頁の変わり目に【KR2a0002_WYG_001-1a】形式のマーカーを保持（底本の `<pb:...>` を変換したもの）。マーカーは独立した1行で、次の1行にその頁の本文全体が入る（頁ごとに1行）
- 原本の行末記号「¶」は除去し、物理行を連結。字下げの全角空白は残る
- 画像リンク（`<md:...>`・`<img:...>`）は除去（史部の底本には該当が無かった）
- 巻ファイルを名前順に統合して1作品1ファイルとし、巻ごとに末尾の空白を除いて改行1つでつなぐ
- 文字コードはUTF-8（BOMなし）、改行はLF
- 割注は底本のとおり `(乾下/乾上)` の形で残る（丸括弧が割注、「/」が割注の中の行替え）。四庫底本の文献には「欽定四庫全書」等の巻頭表記と提要が底本通り残る

検索するときは次の点に注意されたい。

- 頁をまたぐ語は頁マーカー行で分断され、行をまたぐ語には字下げの全角空白や割注の「/」「)(」が挟まることがある
- 同じ文献の中に「教」と「敎」のような異体字が混在する（底本の字体のまま）
- 外字は `&KR0694;` の形の参照のまま残る。計41,317件・2,359種が520文献にあり、最も多い文献は KR2k0009 大清一統志（1,879件）と KR2k0037 天下郡國利病書（1,878件）である。字形は kanripo/KR-Gaiji で確認できる
- 四部叢刊本の文献には、別の集・續集・附録などを同じ巻番号の巻ファイルにまとめて入れているものがある。上流の巻ファイルの途中に、底本ファイルの系列の違う「#+PROPERTY: FILE」の行が複数ある文献は次の5件である: KR2b0015 資治通鑑外紀（本文と目録）、KR2d0014 元朝秘史（續集）、KR2f0037 五朝名臣言行錄（五朝名臣言行錄10巻と三朝名臣言行錄14巻（目録ではこの項の附。catalog.csv の appendix 列）の同じ巻番号が1つの巻ファイルに入っている。四部叢刊本の八朝名臣言行錄）、KR2l0021 三事忠告（為政忠告の3部）、KR2o0001 史通（札記）
- 本文が途中までの正史7件には前の巻の本文の重複があり（上の表）、同じ用例が2回数えられる。件数を数えるときは重複した側の頁（頁マーカーの番号で分かる）を除くこと。同じ本文の頁（80字以上あって1字も違わない頁）のある文献は全部で24件・1,574頁で、うち隣り合う2頁の重複が14文献・140頁である
- 上流のデータに由来する記法が一部に残る: `<折 t="33"/>` 3,429箇所（KR2a0028・KR2b0027・KR2d0016・KR2d0017・KR2d0018・KR2k0037・KR2n0002・KR2n0017・KR2n0044 の9文献。うち KR2n0017 隸釋に2,478箇所、KR2k0037 に891箇所）、`</TEI` 1箇所（KR2a0012）。該当文献は review_flag 列に記した
- KR2b0041 十八史略では、本文の中の【　】は注の見出し語である。頁マーカーは【KR2b0041_MJSY_001-008a】の形で独立した1行にある

## catalog.csv の列

id, subcat, subcat_name（正史類等）, title, era（朝代）, author, date_ca（目録の DATE 欄）, extent（目録の巻数表記）, juan（本体の巻数、整数）, source（目録の SOURCE 欄）, editions（目録の版本欄。SBCKの底本注記は〔　〕内）, persons（目録の人物欄の全員。「名|朝代|職|生没」を「;」で区切る）, appendix（附録などの節。「節名[巻数]{人物}」を「 // 」で区切る）, baseedition（本文ファイルの BASEEDITION＝master の実際の底本）, han_chars（漢字数）, review_flag, status（機械生成・未検証／検証済）, path, witness（採用ブランチ）, repo_status（取得済／取得不能（リポジトリ欠落））, commit（取得時SHA）

title・era・author は目録の見出し行（「題名-朝代-著者」）を分けたものである。したがって era は見出し行の朝代であり、注釈・音義・考證などを加えた人物の朝代は persons 列にある。文字コードはBOM付きUTF-8、581行（見出し行を除く）。
